# R8 retained diagnostics

Every actual process receipt and full stdout/stderr remains in the handoff. Exit
status, log hash, exact command, private paths, timing and observed competing
processes are recorded by the unchanged shared runner. Acceptance uses successful
fresh reruns where listed; failed attempts remain failures.

- The first import request deferred before launch while the owner's Godot
  playtest (PIDs 53152/53468) was active. The shared runner then tried to hash its
  nonexistent prelaunch log and reported that secondary error. No engine was
  launched and no owner process was stopped. After the owner said it was closed,
  the guarded import and both renderer smokes passed. This was process deferral,
  not an automatic approval rejection.
- The first full paid Forward+ run passed 864 of 865 checks but stalled at route
  waypoint 11 after 8.3343505859375 m. The actual checkpoint, failed report and
  log remain. Checkpoint-only diagnostic walks passed with art on and off; the
  full fresh traced rerun passed all 865 checks and walked 135.078021510504 m.
  The original code's route, collision, input and thresholds were not changed.
  Additive tracing records input, pose, velocity, UI/root state and actual slide
  collisions. The initial single failure's cause remains unestablished; a later
  pass is not claimed to explain it. Both renderer art-on/off successful paid
  fingerprints and exact walk records match.
- The initial diagnostic fixture had mixed space/tab indentation and failed to
  parse. Its failed source and log remain. The R8 derivative was normalized to
  spaces; the route assertions were preserved. Successful diagnostics have fresh
  IDs, logs and private states.
- The first R2 projection derivative passed all 16,676 checks but inherited an
  old terminal ObjectDB leak warning. An R8 copy now uses the already checked R4
  terminal helper after the same assertions. Its fresh rerun passes all 16,676
  checks, releases fixture descendants and observed playback references, and has
  no ObjectDB leak warning. The old result remains a diagnostic run.

The eight original R4 repaired fixtures have 44 fresh successful flow/restore
jobs across both renderers. Every terminal report has zero fixture children and
zero observed playback references; none reports ObjectDB instances leaked. This
is bounded fixture evidence, not an ordinary-game shutdown or long-session claim.

An early commentary mentioned 120 cursor-visible frames for the smoke runs.
That claim was corrected: those logs established startup conditions only, because
120 physics frames did not imply 120 process-frame observations. A separate
`comfort-live` fixture checks 120 actual rendered player process frames, asserting
both visible mouse mode and the window's real no-focus flag on every frame.

Unit checks retain their expected invalid-input diagnostics. Compatibility feature
warnings, if present, stay in the raw logs. Fatal script/engine errors are neither
suppressed nor overridden by assertion counts. No automatic approval rejection
has occurred during this work.

The comparison source audit caught a Windows default-code-page error before any
performance measurements. Nine player UI text lines in each private test copy had
been transcoded incorrectly. They were restored from original UTF-8 bytes; a
strict byte assertion now permits only the explicit mouse-capture branch change.
Seven owned fixture copies also had caption-only encoding changes; their original
caption bytes were restored. All before files and exact changed lines remain in
`evidence/encoding-diagnostic`. No assertion, simulation, geometry, shader or route
logic changed. Earlier captures and state checks remain actual evidence from that
recorded UI-text variant. Fresh imports and untraced paid/restart/probe checks use
the final bytes; all cost measurements use the final bytes. Tools now use explicit
UTF-8 or byte operations.

R6's imported source helper generated one ignored Python bytecode file in this
worktree's inherited tool directory. Its timestamp matched the R8 reopen job. That
single file was moved into R8's ignored diagnostic directory, and the now-empty
cache directory removed. No tracked parent source changed. The preparation recipe
now disables bytecode before the helper import; the previously executed derivative
is retained as evidence. Generated bytecode is excluded from the handoff.

All four final-byte untraced paid flows passed 865 checks, all four restores passed
eight, and all four probes passed ten. Their complete initial/paid/final fingerprints
and 135.078021510504 m route records equal the prior successful runs. All 24 isolated
camera jobs and six uncaptured traversals passed with no recorded competing process.
The higher settled-frame costs and remaining roughly 451-453 ms R8 traversal stalls
