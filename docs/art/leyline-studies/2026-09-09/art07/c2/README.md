# ART-07C2 actual source review

These are source candidates for Glasswind/Shellcut, with technical acceptance
separate from owner visual acceptance. The [technical receipt](../../../../../prototype/art07-production/receipts/c2.md)
records native state, dimensions, lineage, checks, package hash and limits.

`shellstone-input-v01.png` is the single-object production input. Everything
prefixed `blender-`, `forward_plus-` or `gl_compatibility-` is an actual finished
model render or an animation encoded from actual Godot viewport frames. No
concept image is used as evidence of the finished model.

Slate's split layers are geometry and remain visible in silhouette. The generated
shellstone retains a fan and irregular partial circular fossils; fine coils are
softened, and its second orientation repeats the same source population. Tussocks
have a green interior, dry rims and opaque rooted blades. The flat composed
review makes the approach, work-state family, distant source context and detail
transitions inspectable, but it is not a generated landscape or final biome art.

The two renderers differ in brightness and grass shading. Inherited B3 shelves
still have conspicuous source texture patterns at close range. Distant B1 pine
retains the B4 body-fit limitation; it is only decorative context in this review.
Ordinary quarry and grass are unlit. Scar-off/on and pulse animations show the
inherited shelf's existing recessed ambient energy, with no gameplay meaning.

Native full/half-worked/last/depleted and separate-process restore views use the
real current resource rules in an isolated authored fixture. `native-depletion`
animations show the original shrink timing and session-only aftermath. No test
material grant pays for the quarry work, and no normal save is loaded.

`measurements.json`, renderer benchmark/check JSON, native flow/restart JSON,
`audit-v05.json`, `check-summary.json` and `motion-verification.json` retain
machine-readable results. Complete raw frames, hidden-side renders, packed
master, raw generation, projects and logs are in the ignored local handoff.
