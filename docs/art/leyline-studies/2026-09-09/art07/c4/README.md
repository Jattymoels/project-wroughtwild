# ART-07C4 actual model evidence

See the [C4 receipt](../../../../../prototype/art07-production/receipts/c4.md)
for the selected package, exact hashes, commands, renderer costs and limitations.
The ash input is the single-object source illustration. All Blender/Godot
images and WebP animations here show delivered models, not imagegen substitutes.

- blender-ash.png: actual standing variants, felled timber and session stump.
- blender-scrub.png and blender-scar-off.png: actual source geometry.
- forward_plus / gl_compatibility habitat and scar panels: actual day/dusk and
  same-clock light-disabled/enabled views from each renderer.
- pulse.webp: four-second ambient host cycle from forty-eight rendered samples.
- wind.webp: 5.5-second rooted scrub cycle from forty-eight rendered samples.
- walk.webp: sampled actual 36.38 m CharacterBody traversal, approximately real time.
- native-felling.webp: actual ResourceNode fall frames, slowed roughly twofold
  for review; stock and restart results are in the adjacent JSON records.

WebP clips retain selected real frames and resize them; they do not interpolate
or generate missing frames. Full original PNG sequences remain in the local
handoff. The native fixture poses the biome and directly invokes work/pickup;
it does not represent paid campaign play. Owner visual acceptance is pending.
