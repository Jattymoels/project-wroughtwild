# ART-07E3 — actual chest and fire-setting models

Selected source and evidence bundle: v10. The Godot captures use the v08
inspection framing in the fresh frozen-game review (`r04`). Technical delivery and package hashes are in
the [E3 receipt](../../../../../prototype/art07-production/receipts/e3.md).
Owner visual acceptance remains pending.

Eight legal chest families share supported articulated joinery and native
storage. Five legal fuels share the existing finite burn/heat contract. These
are directly modelled mechanisms using unchanged D4/D5/D6 material maps, not a
generated scene board. Every principal PNG is an unchanged actual Blender or
Godot render. Contact sheets only resize/label those renders. `v10/manifest.json`
records source paths and SHA-256 hashes for every selected or derived artifact.
JSON copies use LF line endings so these hashes survive a Git checkout.
The corrected v10 Blender inspector excludes hidden reference objects and
requires every GLB's exact source triangle count and evaluated bounds. All
runtime GLB bytes are unchanged from the gameplay-tested v06 models.

`blender-wood-open.png`, `blender-wood-closed.png` and `blender-six-angle.png`
show the reopened packed model and closed underside. Each renderer directory
has all-family sheets, real native storage/ghosts, shaded/dusk views, new fuel,
late ash, emission-off geometry and the genuinely removed spent scene.

The animated WebPs encode real engine frames at 960 × 600. Lid frames use a
fixed 1/30-second cosmetic step following native panel open/close; display is
retimed to 80 ms per frame. Fire frames step the original native burn method
from seconds 0–44, displayed at 120 ms per frame, then show the actual spent
scene at second 60. They prove state-linked motion, not real-time burn duration
or normal gameplay animation speed. Benchmark JSON retains the separate v07
runs: the benchmark function, cameras, settings, meshes and materials are
unchanged by v08's close fire inspection framing.

The higher inspection angle reveals the recessed embers. At native age 12 s,
emission on/off changes 3,753 pixels by more than 5/255 in both renderers outside
the caption, with the native point light unchanged. The two comparison JSONs
and source hashes make this visible-light check reproducible.

The chest has more regular joinery and surfaces than the concept. Its existing
grid offset embeds the bottom .15 m in the flat review floor. Fire is a low
ember pile with no flame card or smoke; Compatibility is brighter than
Forward+. No furnished-world or lower-spec performance acceptance is claimed.
No gameplay tuning, resource stock, save fields or ordinary game files change.
