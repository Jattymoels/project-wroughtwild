# C3 actual source and native-state evidence

These are unretouched Blender/Godot captures and WebPs sampled from actual
engine frames. The complete source-resolution sequences, additional angles,
logs and packed source are retained in the local handoff recorded by the
[C3 receipt](../../../../../prototype/art07-production/receipts/c3.md).
See that receipt for hashes, dimensions, limitations and publication status.

- `blender-hero*`: full-width source study. Its buttressed footprint **does not
  fit the native tree body**; this model is not used in the work/physical fixture.
- `blender-cork-full` and `blender-amber-cut`: actual thick porous sleeves and
  cut-grain material specimens. Ordinary material is non-emitting.
- Renderer-prefixed `day`, `dusk` and `incision-*`: fitted tree candidates and
  deadfall, including emission-off damage. The slimmer lower trunk is an explicit
  unresolved visual compromise; successful rendering is not art acceptance.
- `cork-worked` and `native-partial`: exposed independent finite bark states.
- `pulse`, `wind`, `walk`, `native-fall`: engine motion, no generated/interpolated
  frames. Each renderer also has twelve identical paused source frames; the
  image verification records this separately.

`media-manifest.json` hashes these exact Git media bytes. Reports include all
23 independent export audits, source lineage, texture cooking and the slice's
own quiet-window measurements. The complete study is a sparse authored flat
patch, not a generated or owner-accepted oldgrowth habitat.
