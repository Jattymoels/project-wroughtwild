# Progression baseline worksheet — Codex, 5 September 2026

**Author: Codex (OpenAI), not Claude.** Proposed playtest; no measurements
have been collected and no loot or crafting numbers have been retuned.

Start a fresh seed-1 Warden session on a recorded commit. Keep the art
variant fixed for repeats. Record session duration, stop condition and
familiarity with the seed before starting. Do not compare a fresh run with
a developer-supplied inventory or unlocks.

Goal: prepare for the first trial and return to improve the workshop.
Record transitions between these mutually exclusive activities: combat,
gathering, travel, building and menus. If evaluating loot while fighting,
classify that interval as combat and note the interruption. Record pauses
separately and exclude them from active-play totals.

Use the baseline to select one subsequent experiment: source/era eligibility,
a fen deposit, or fewer finished items with a distinctive harvesting reward.
Define its intended experience and repeat this protocol before combining
changes. One familiar-seed run cannot establish drop balance or generation
guarantees.
