# LAND-00 planning visuals

Both images are proposals, not actual game screenshots and not implementation evidence.

- [01-scarwater-concept.png](01-scarwater-concept.png): original AI-generated direction board, built-in imagegen, 16 September 2026. Generated from the [exact text prompt](image-prompt.txt), with no input reference image supplied to the generator. It interprets the project's written lore/reference qualities; it is not a copied owner reference or a runtime asset. Saved project copy retains the selected output.
- [02-scarwater-layout.png](02-scarwater-layout.png): original programmatically drawn planning diagram using Pillow from the bundled local runtime. It explains route, home, source, habitat and native fissure relationships. It is schematic, not to scale and not generated game geometry. Drawing script is disposable planning scratch at `build/land00/draw_layout.py`, not a game dependency.

The generated board was inspected for the requested composition and label clarity. It provides a strong spatial target but has richer foliage/material finish than current gameplay. Its small containment clamp is illustrative, not a new item/recipe. Furnishings on the shelf imply future player construction. First-slice implementation should use the existing paid pressure machinery and simpler controlled art with equivalent composition.

Do not infer a flowing river, unlimited ridge height, free buildings, resource renewal, region-control mechanic or tested lighting quality from the board. The layout's 250–350 m span and 20–35 m relief are initial unmeasured design targets; exact geometry is LAND-01 work. Real fixed water, cave access, old saves and source ownership remain authoritative.

Actual retained runtime evidence is separately linked in the [main report](../land00-creative-discovery-result-2026-09-16.md). Owner originals remain in their [reference library](../../art/references/environment/2026-09-14-reclaimed-frontier/README.md), with their provenance/interpretation caveats intact.

No external art is added to the game, no paid service is selected, and the images do not establish owner aesthetic approval.
